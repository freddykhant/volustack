# The Coach Box Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A text input on the week board where the athlete types a scheduling request or one of four questions, a language model turns it into a strict form, and the reply is built from engine facts.

**Architecture:** The model (Claude, through one forced tool) is a parser: it returns an intent, dates and a session key, nothing else. A pure resolver checks that form against the real week and produces a typed reply whose every string comes from phrasing functions over dates, labels and engine facts. Changes go through a confirm card into plural versions of the existing exception procedures; skipping reuses the missed-session dialog; the existing replacement panel does the rest.

**Tech Stack:** Next.js 15 App Router, React 19, tRPC 11, Prisma 6 on Postgres (`prisma db push`), Zod, Vitest 4 + fast-check, Tailwind v4 tokens, `@anthropic-ai/sdk`.

**Spec:** `docs/superpowers/specs/2026-10-14-coach-box-design.md`

## Global Constraints

- **The model never writes what the athlete reads.** Its only output is the intent form. No string from a model response is rendered, and none is stored except the parsed form in `CoachMessage.form`.
- **Law 1:** nothing here changes sets, reps, RIR or volume.
- **Law 2:** every `summary`, `question` and `lines` string is produced by a pure phrasing function from dates, session labels and engine facts.
- **No change without a tap.** `coach.interpret` changes no schedule state. Writes happen only from a confirm card, through `schedule.setExceptions` / `clearExceptions` or the existing missed-session dialog.
- **The form is the boundary.** Every field of the form is validated against the real week before use: dates must be in the allowed set (today to block end), dayparts must fit the schedule mode, the session key must be in the server's key map.
- **Least context.** The model is sent dates, weekday names, session labels, statuses and blocked flags for the signed-in athlete only. Never a database id, an email, profile data or earlier messages.
- **Engine purity:** `src/engine/**` and `src/domain/**` are synchronous and do no I/O. `src/views/**` imports nothing from `src/server`.
- **Every schedule write runs under `lockActiveBlock`** in a transaction with `{ timeout: 15000 }`.
- **Limits, exact values:** message text 1 to 500 characters after trimming; at most 14 dates in a form; at most 14 cells per `setExceptions` / `clearExceptions` call; `COACH_DAILY_LIMIT = 50` messages per athlete per rolling 24 hours; model timeout 8000 ms; no retry; `max_tokens` 400.
- **Model:** env `COACH_MODEL`, default `claude-sonnet-5-5`. Key: env `ANTHROPIC_API_KEY`, optional. With no key the coach box is not rendered and `coach.interpret` returns the `unavailable` reply.
- **Vocabulary:** "coach box", "intent form", "resolve", "reply", "session key". "Reschedule" keeps meaning set redistribution.
- **The ambiguity rules in the system prompt are reserved for the product owner.** Ship the placeholder block exactly as given in Task 5. Do not expand it.
- Never run `prisma db push` with `--accept-data-loss` or `--force-reset`. Never print values from `.env`.
- Match the surrounding code's comment density and naming. Work on branch `freddy/feat/coach-box`. Do not push.
- Commands: `pnpm vitest run <path>`, `pnpm typecheck`, `pnpm lint`.

## Refinements made during planning (the spec is amended to match)

1. **The coach box is rendered by `ScheduleBoard`, at its top,** not by the week page. It needs to know when a drag draft is open and to hand results to the board's notice.
2. **A ninth reply kind, `note`,** carries a plain engine-built line when there is nothing to confirm (for example, everything asked for is already blocked).
3. **`COACH_DAILY_LIMIT` lives in `src/schema/coach.ts`,** not in the engine's constants. It is not an engine concern.
4. **The resolver receives `explain` as a function** and the week as plain data, so it does not depend on the engine's input shape. The router supplies both.
5. **"Re-arrange" does not scroll the page.** Its lines point to the options below the box.
6. **`PlacementExplanation` gains `better: Placement | null`,** the cell the engine would choose when the current one is not the best. `isBest` is `better === null`.
7. **`loadWeekContext` and `lockActiveBlock` move** from the schedule router to `src/server/schedule/week-context.ts`, unchanged, so the coach router can use them.

## Review Focus

1. **A model response that is not the form** (no tool use, extra fields, a date that was never offered, a session key that does not exist, 30 dates). The athlete gets the fixed `unavailable` line or a clarify, never an error page and never a write. (Tasks 4, 5, 7 tests.)
2. **"Away Thursday to Saturday" when Friday is already blocked.** The confirm card offers Thursday and Saturday and says Friday already is. (Task 4 test.)
3. **A half-day named by an athlete on one-a-day mode.** The whole day is offered and no half-day cell ever reaches `setExceptions`. (Task 4 property.)
4. **Dates near midnight in a non-UTC timezone.** "Today" in the context and in the allowed set is the athlete's local date. (Task 5 test, Perth.)
5. **The 51st message of the day.** No model call is made and nothing is logged. (Task 7 test.)

```ts
import { z } from "zod";
import { DaypartEnum } from "./enums";
import { ExceptionInputSchema, IsoDateSchema } from "./schedule";

/** Messages one athlete may send the coach in any 24 hours. */
export const COACH_DAILY_LIMIT = 50;
export const COACH_MAX_DATES = 14;
export const COACH_MAX_TEXT = 500;

/** Everything the coach box can be asked to do or answer. */
export const CoachIntentEnum = z.enum([
  "block_time",
  "unblock_time",
  "skip_session",
  "rearrange_week",
  "ask_week_issues",
  "ask_why_placement",
  "ask_next_session",
  "ask_recovery",
  "unclear",
  "out_of_scope",
]);
export type CoachIntent = z.infer<typeof CoachIntentEnum>;

/**
 * The only thing the language model may return. It is parsed here and then checked
 * field by field against the real week; nothing in it is trusted as it arrives.
 */
export const CoachIntentFormSchema = z.object({
  intent: CoachIntentEnum,
  /** Dates the message refers to. Empty when it names none. */
  dates: z.array(z.object({ date: IsoDateSchema, daypart: DaypartEnum.nullable() })).max(COACH_MAX_DATES),
  /** A session key from the context ("S1"), or null. */
  sessionKey: z
    .string()
    .regex(/^S\d{1,2}$/)
    .nullable(),
});
export type CoachIntentForm = z.infer<typeof CoachIntentFormSchema>;

export const CoachMessageInputSchema = z.object({
  weekIndex: z.number().int().min(1),
  text: z.string().trim().min(1).max(COACH_MAX_TEXT),
});
export type CoachMessageInput = z.infer<typeof CoachMessageInputSchema>;

/** Several one-off cells to block or unblock in one transaction. */
export const ExceptionCellsInputSchema = z.object({
  cells: z.array(ExceptionInputSchema).min(1).max(COACH_MAX_DATES),
});
export type ExceptionCellsInput = z.infer<typeof ExceptionCellsInputSchema>;
```

```ts
export interface PlacementAlternative {
  to: Placement;
  /** Cost change if the session moved there: positive is worse. */
  delta: number;
  /** Problems the move would create that the current layout does not have. */
  adds: DecisionFact[];
  /** Problems of the current layout the move would remove. */
  resolves: DecisionFact[];
}

export interface PlacementExplanation {
  sessionId: string;
  current: Placement;
  /** Facts of the current layout that name this session. */
  currentFacts: DecisionFact[];
  /** The nearest free cell before and after the current one, each compared. */
  alternatives: PlacementAlternative[];
  /** The cell the engine would choose instead, or null when this one is the best. */
  better: Placement | null;
  isBest: boolean;
}

/** The sessions a schedule fact is about. Week-wide facts name none. */
function factSessionIds(f: DecisionFact): string[] {
  switch (f.kind) {
    case "short_rest":
      return f.otherSessionId === null ? [f.sessionId] : [f.sessionId, f.otherSessionId];
    case "same_day_stack":
      return [...f.sessionIds];
    case "off_preference":
    case "on_blocked_cell":
      return [f.sessionId];
    default:
      return [];
  }
}

/**
 * Why a session is where it is, as a comparison: what the nearest free time before and
 * after it would cost, in the same facts the board warns with. Reads placements and
 * footprints only. Null for a session that cannot move or is not on the board.
 */
export function explainPlacement(input: ScheduleInput, layout: Layout, sessionId: string): PlacementExplanation | null {
  const session = input.sessions.find((s) => s.id === sessionId);
  const current = layout[sessionId];
  if (!session || current === undefined || isFixed(session)) return null;

  const base = scoreLayout(input, layout);
  const baseIds = new Set(base.facts.map(factIdentity));
  const here = placementPosition(current, input.weekStartDay);
  const held = heldCells(input, layout);
  const free = openCells(input).filter((c) => !held.has(cellKey(c, input.mode)));

  const compare = (to: Placement): PlacementAlternative => {
    const after = scoreLayout(input, { ...layout, [sessionId]: to });
    const afterIds = new Set(after.facts.map(factIdentity));
    return {
      to,
      delta: Math.round((after.cost - base.cost) * 1e6) / 1e6,
      adds: after.facts.filter((f) => !baseIds.has(factIdentity(f))),
      resolves: base.facts.filter((f) => !afterIds.has(factIdentity(f))),
    };
  };

  const earlier = free.filter((c) => placementPosition(c, input.weekStartDay) < here).at(-1);
  const later = free.find((c) => placementPosition(c, input.weekStartDay) > here);
  const alternatives = [earlier, later].filter((c): c is Placement => c !== undefined).map(compare);

  let better: Placement | null = null;
  let bestCost = base.cost;
  for (const c of free) {
    const cost = scoreLayout(input, { ...layout, [sessionId]: c }).cost;
    if (cost < bestCost - SCHEDULE_EPS) {
      bestCost = cost;
      better = c;
    }
  }

  return {
    sessionId,
    current,
    currentFacts: base.facts.filter((f) => factSessionIds(f).includes(sessionId)),
    alternatives,
    better,
    isBest: better === null,
  };
}
```

```ts
import { dayNumberOfIsoDate, weekdayOfDayNumber } from "~/domain/local-day";
import type { Placement, PlacementAlternative, PlacementExplanation } from "~/engine/schedule";
import type { ExceptionInput } from "~/schema";
import { DAY_NAMES, toWarnings } from "~/views/schedule";
import type { ReadinessLabel } from "~/views/types";

/** A reply that needs no further question. */
export type CoachFinalReply =
  | { kind: "confirm_block"; cells: ExceptionInput[]; summary: string; alreadyBlocked: string[] }
  | { kind: "confirm_unblock"; cells: ExceptionInput[]; summary: string; notes: string[] }
  | { kind: "skip"; sessionId: string; label: string; summary: string }
  | { kind: "rearrange"; state: "options" | "suggestion" | "nothing"; lines: string[] }
  | { kind: "answer"; topic: "week_issues" | "why_placement" | "next_session" | "recovery"; lines: string[] }
  | { kind: "note"; lines: string[] }
  | { kind: "unsupported"; lines: string[] }
  | { kind: "unavailable"; lines: string[] };

/** What the coach box shows. A clarify's choices are complete replies, so it never nests. */
export type CoachReply =
  | CoachFinalReply
  | { kind: "clarify"; question: string; choices: { label: string; reply: CoachFinalReply }[] };

export interface NextSessionInfo {
  label: string;
  placement: Placement | null;
  minutes: number;
  first: { exerciseName: string; sets: number; repLow: number; repHigh: number } | null;
}

export interface ReadinessInfo {
  fitness: number;
  fatigue: number;
  form: number;
  label: ReadinessLabel;
}

export const DAY_FULL = ["Monday", "Tuesday", "Wednesday", "Thursday", "Friday", "Saturday", "Sunday"] as const;
const MONTHS = ["Jan", "Feb", "Mar", "Apr", "May", "Jun", "Jul", "Aug", "Sep", "Oct", "Nov", "Dec"] as const;

export function joinList(items: string[]): string {
  if (items.length <= 1) return items[0] ?? "";
  return `${items.slice(0, -1).join(", ")} and ${items[items.length - 1]}`;
}

/** "Thu 15 Oct" for a "YYYY-MM-DD" calendar date. */
export function dateLabel(iso: string): string {
  const weekday = DAY_NAMES[weekdayOfDayNumber(dayNumberOfIsoDate(iso))] ?? "?";
  return `${weekday} ${Number(iso.slice(8, 10))} ${MONTHS[Number(iso.slice(5, 7)) - 1] ?? "?"}`;
}

const HALF = { AM: "morning", PM: "afternoon" } as const;

export function cellLabel(cell: ExceptionInput): string {
  return cell.daypart ? `${dateLabel(cell.date)} (${HALF[cell.daypart]})` : dateLabel(cell.date);
}

export function placeName(p: Placement): string {
  const day = DAY_FULL[p.day] ?? "?";
  return p.daypart ? `${day} ${HALF[p.daypart]}` : day;
}

export function blockSummary(cells: ExceptionInput[]): string {
  return `Block ${joinList(cells.map(cellLabel))}?`;
}

export function unblockSummary(cells: ExceptionInput[]): string {
  return `Unblock ${joinList(cells.map(cellLabel))}?`;
}

export function skipSummary(label: string, placement: Placement | null): string {
  return placement ? `Skip ${label} on ${placeName(placement)} this week?` : `Skip ${label} this week?`;
}

/** A cost change this small is not worth telling the athlete about. */
const ABOUT_THE_SAME = 0.5;

function phraseAlternative(a: PlacementAlternative, label: (id: string) => string): string {
  const place = placeName(a.to);
  const problems = toWarnings(a.adds, label);
  if (problems.length > 0) return `If it moved to ${place}: ${problems.join(" ")}`;
  if (a.delta < -ABOUT_THE_SAME) return `${place} would be better.`;
  if (a.delta > ABOUT_THE_SAME) return `${place} would space the week a little less evenly.`;
  return `${place} would be about the same.`;
}

/** Why a session is where it is. Every clause comes from the explanation's own facts. */
export function phraseExplanation(ex: PlacementExplanation, label: (id: string) => string): string[] {
  const name = label(ex.sessionId);
  const lines = [`${name} is on ${placeName(ex.current)}.`];
  const now = toWarnings(ex.currentFacts, label);
  if (now.length > 0) lines.push(`Right now: ${now.join(" ")}`);
  if (ex.alternatives.length === 0) {
    lines.push("There is no other open time for it this week.");
    return lines;
  }
  for (const a of ex.alternatives) lines.push(phraseAlternative(a, label));
  lines.push(
    ex.better
      ? `The engine would put it on ${placeName(ex.better)}.`
      : `${placeName(ex.current)} is the best open spot the engine sees this week.`,
  );
  return lines;
}

export function phraseNextSession(next: NextSessionInfo | null): string[] {
  if (next === null) return ["Every session this week is done or missed."];
  if (next.placement === null) return [`Next up is ${next.label}. It isn't placed on a day yet.`];
  const lines = [`Next up is ${next.label} on ${placeName(next.placement)}, about ${next.minutes} minutes.`];
  if (next.first) {
    lines.push(`It starts with ${next.first.exerciseName}, ${next.first.sets} sets of ${next.first.repLow} to ${next.first.repHigh}.`);
  }
  return lines;
}

const one = (n: number) => (Math.round(n * 10) / 10).toFixed(1);

/** Readiness as the model computed it. No advice: the label is the engine's own word. */
export function phraseRecovery(r: ReadinessInfo | null): string[] {
  if (r === null) return ["There isn't enough logged training yet to read your recovery."];
  return [`Your form reads ${r.label}.`, `Fitness ${one(r.fitness)}, fatigue ${one(r.fatigue)}, form ${one(r.form)}.`];
}

export function phraseWeekIssues(
  warnings: string[],
  suggestion: { headline: string; reasons: string[] } | null,
): string[] {
  if (warnings.length === 0 && suggestion === null) return ["No warnings this week."];
  return suggestion ? [...warnings, `Suggested: ${suggestion.headline}`] : [...warnings];
}

export const UNSUPPORTED_LINES = [
  "I can't help with that yet.",
  "I can block or unblock time, skip a session, re-arrange the week, and tell you what's wrong with the week, why a session is where it is, what's next, and how your recovery reads.",
];
export const UNAVAILABLE_LINES = ["I couldn't work that out just now. You can still block time from the board."];
export const LIMIT_LINES = ["You've reached today's limit for the coach. The board still works."];
export const FINISHED_WEEK_LINES = ["That week is over, so there is nothing to change in it."];
```

```ts
import type { Placement, PlacementExplanation } from "~/engine/schedule";
import type { CoachIntentForm, ExceptionInput, ScheduleMode } from "~/schema";
import {
  blockSummary,
  cellLabel,
  dateLabel,
  phraseExplanation,
  phraseNextSession,
  phraseRecovery,
  phraseWeekIssues,
  skipSummary,
  unblockSummary,
  UNSUPPORTED_LINES,
  type CoachFinalReply,
  type CoachReply,
  type NextSessionInfo,
  type ReadinessInfo,
} from "~/views/coach";

/** How a half-day is blocked, if it is. */
export type BlockSource = "standing" | "one_off" | null;

export interface CoachDate {
  date: string; // "YYYY-MM-DD"
  weekday: number; // 0 = Mon … 6 = Sun
  weekIndex: number;
  am: BlockSource;
  pm: BlockSource;
}

export interface CoachSession {
  key: string; // "S1": the stand-in the model sees
  id: string;
  label: string;
  status: "SCHEDULED" | "COMPLETED" | "MISSED";
  placement: Placement | null;
}

/** Everything the resolver needs about the athlete's week, as plain data. */
export interface CoachWeek {
  mode: ScheduleMode;
  weekIndex: number;
  /** Every date from today to the block's last day, ascending. The only dates a form may use. */
  dates: CoachDate[];
  /** The viewed week's sessions, in board order. */
  sessions: CoachSession[];
  stranded: boolean;
  warnings: string[];
  suggestion: { headline: string; reasons: string[] } | null;
  next: NextSessionInfo | null;
  readiness: ReadinessInfo | null;
  explain: (sessionId: string) => PlacementExplanation | null;
}

type Half = "AM" | "PM";
const HALVES: Half[] = ["AM", "PM"];
const sourceOf = (d: CoachDate, half: Half): BlockSource => (half === "AM" ? d.am : d.pm);
const whole = (date: string): ExceptionInput => ({ date, daypart: null });
const note = (...lines: string[]): CoachFinalReply => ({ kind: "note", lines });

/**
 * The halves the form asks about, per allowed date, in date order. Dates the model was
 * never offered are dropped here, so nothing after this point can see one. In one-a-day
 * mode a half-day means the day.
 */
function wantedHalves(form: CoachIntentForm, week: CoachWeek): { day: CoachDate; halves: Half[] }[] {
  const byDate = new Map(week.dates.map((d) => [d.date, d]));
  const wanted = new Map<string, Set<Half>>();
  for (const d of form.dates) {
    if (!byDate.has(d.date)) continue;
    const set = wanted.get(d.date) ?? new Set<Half>();
    if (week.mode === "DAY" || d.daypart === null) HALVES.forEach((h) => set.add(h));
    else set.add(d.daypart);
    wanted.set(d.date, set);
  }
  return week.dates
    .filter((d) => wanted.has(d.date))
    .map((d) => ({ day: d, halves: HALVES.filter((h) => wanted.get(d.date)!.has(h)) }));
}

/** One cell for a set of halves on a date: the whole day when both, else the half. */
function cellFor(date: string, halves: Half[]): ExceptionInput {
  return halves.length === 2 ? whole(date) : { date, daypart: halves[0]! };
}

function blockReply(asked: { day: CoachDate; halves: Half[] }[], week: CoachWeek): CoachFinalReply | null {
  const cells: ExceptionInput[] = [];
  const already: string[] = [];
  for (const { day, halves } of asked) {
    if (week.mode === "DAY") {
      // A day is blocked only when both halves are; otherwise the whole day is still to block.
      if (day.am !== null && day.pm !== null) already.push(dateLabel(day.date));
      else cells.push(whole(day.date));
      continue;
    }
    const open = halves.filter((h) => sourceOf(day, h) === null);
    const blocked = halves.filter((h) => sourceOf(day, h) !== null);
    if (open.length > 0) cells.push(cellFor(day.date, open));
    if (blocked.length > 0) already.push(cellLabel(cellFor(day.date, blocked)));
  }
  if (cells.length > 0) return { kind: "confirm_block", cells, summary: blockSummary(cells), alreadyBlocked: already };
  if (already.length > 0) return note(...already.map((a) => `${a} is already blocked.`));
  return null;
}

function unblockReply(asked: { day: CoachDate; halves: Half[] }[], week: CoachWeek): CoachFinalReply | null {
  const cells: ExceptionInput[] = [];
  const notes: string[] = [];
  const open: string[] = [];
  for (const { day, halves } of asked) {
    const oneOff = halves.filter((h) => sourceOf(day, h) === "one_off");
    const standing = halves.filter((h) => sourceOf(day, h) === "standing");
    if (oneOff.length > 0) cells.push(week.mode === "DAY" ? whole(day.date) : cellFor(day.date, oneOff));
    if (standing.length > 0 && oneOff.length === 0) {
      const label = week.mode === "DAY" ? dateLabel(day.date) : cellLabel(cellFor(day.date, standing));
      notes.push(`${label} is blocked in your standing availability. Change that in Settings.`);
    }
    if (oneOff.length === 0 && standing.length === 0) {
      open.push(week.mode === "DAY" ? dateLabel(day.date) : cellLabel(cellFor(day.date, halves)));
    }
  }
  if (cells.length > 0) return { kind: "confirm_unblock", cells, summary: unblockSummary(cells), notes };
  if (notes.length > 0) return note(...notes);
  if (open.length > 0) return note(...open.map((o) => `${o} isn't blocked.`));
  return null;
}

/** A clarify with at least one choice, or the fallback when there is nothing to choose from. */
function clarify(question: string, choices: { label: string; reply: CoachFinalReply }[], fallback: CoachFinalReply): CoachReply {
  return choices.length > 0 ? { kind: "clarify", question, choices } : fallback;
}

function whyReply(session: CoachSession, week: CoachWeek): CoachFinalReply {
  const lines =
    session.status === "COMPLETED"
      ? [`${session.label} is already done, so it stays where it was.`]
      : session.status === "MISSED"
        ? [`${session.label} was missed, so it stays where it was.`]
        : session.placement === null
          ? [`${session.label} isn't placed on a day yet.`]
          : (() => {
              const ex = week.explain(session.id);
              const label = (id: string) => week.sessions.find((s) => s.id === id)?.label ?? "Session";
              return ex ? phraseExplanation(ex, label) : [`${session.label} can't be moved right now.`];
            })();
  return { kind: "answer", topic: "why_placement", lines };
}

function skipReply(session: CoachSession): CoachFinalReply {
  if (session.status === "COMPLETED") return note(`${session.label} is already done.`);
  if (session.status === "MISSED") return note(`${session.label} was already missed.`);
  return { kind: "skip", sessionId: session.id, label: session.label, summary: skipSummary(session.label, session.placement) };
}

const answer = (topic: "week_issues" | "next_session" | "recovery", lines: string[]): CoachFinalReply => ({
  kind: "answer",
  topic,
  lines,
});

/**
 * Turn the model's intent form into what the coach box shows. Everything in the form is
 * checked against the week here: a date the athlete cannot use, a half-day in one-a-day
 * mode, or a session that is not theirs never reaches a reply. Pure, and never throws.
 */
export function resolveCoachForm(form: CoachIntentForm, week: CoachWeek): CoachReply {
  const session = form.sessionKey === null ? undefined : week.sessions.find((s) => s.key === form.sessionKey);
  const scheduled = week.sessions.filter((s) => s.status === "SCHEDULED");
  const thisWeek = week.dates.filter((d) => d.weekIndex === week.weekIndex);
  const nothingLeft = note("Every session this week is done or missed.");

  switch (form.intent) {
    case "block_time": {
      const asked = wantedHalves(form, week);
      const reply = blockReply(asked, week);
      if (reply) return reply;
      const choices = thisWeek
        .map((d) => ({ label: dateLabel(d.date), reply: blockReply([{ day: d, halves: HALVES }], week) }))
        .filter((c): c is { label: string; reply: CoachFinalReply } => c.reply?.kind === "confirm_block");
      return clarify("Which day can't you train?", choices, note("Every remaining day this week is already blocked."));
    }
    case "unblock_time": {
      const asked = wantedHalves(form, week);
      const reply = unblockReply(asked, week);
      if (reply) return reply;
      const choices = thisWeek
        .map((d) => ({ label: dateLabel(d.date), reply: unblockReply([{ day: d, halves: HALVES }], week) }))
        .filter((c): c is { label: string; reply: CoachFinalReply } => c.reply?.kind === "confirm_unblock");
      return clarify("Which blocked time should I open up?", choices, note("Nothing is blocked just for this week."));
    }
    case "skip_session": {
      if (session) return skipReply(session);
      if (scheduled.length === 1) return skipReply(scheduled[0]!);
      return clarify(
        "Which session do you want to skip?",
        scheduled.map((s) => ({ label: s.label, reply: skipReply(s) })),
        nothingLeft,
      );
    }
    case "rearrange_week": {
      if (week.stranded) {
        return { kind: "rearrange", state: "options", lines: ["A session is on time you've blocked. Your options are just below."] };
      }
      if (week.suggestion) {
        return {
          kind: "rearrange",
          state: "suggestion",
          lines: [week.suggestion.headline, ...week.suggestion.reasons, "You can accept it on the board below."],
        };
      }
      return { kind: "rearrange", state: "nothing", lines: ["The engine has no change to suggest for this week."] };
    }
    case "ask_week_issues":
      return answer("week_issues", phraseWeekIssues(week.warnings, week.suggestion));
    case "ask_why_placement": {
      if (session) return whyReply(session, week);
      return clarify(
        "Which session do you mean?",
        scheduled.map((s) => ({ label: s.label, reply: whyReply(s, week) })),
        nothingLeft,
      );
    }
    case "ask_next_session":
      return answer("next_session", phraseNextSession(week.next));
    case "ask_recovery":
      return answer("recovery", phraseRecovery(week.readiness));
    case "unclear":
      return {
        kind: "clarify",
        question: "I didn't catch that. Did you mean one of these?",
        choices: [
          { label: "What's wrong with my week?", reply: answer("week_issues", phraseWeekIssues(week.warnings, week.suggestion)) },
          { label: "What's next?", reply: answer("next_session", phraseNextSession(week.next)) },
          { label: "How's my recovery?", reply: answer("recovery", phraseRecovery(week.readiness)) },
        ],
      };
    case "out_of_scope":
      return { kind: "unsupported", lines: UNSUPPORTED_LINES };
  }
}
```

```ts
import { isoDateOfDayNumber, localDayNumber, weekdayOfDayNumber } from "~/domain/local-day";
import type { BlockSource, CoachDate, CoachWeek } from "~/domain/coach/resolve";
import type { AvailabilityCellInput } from "~/engine";
import type { ExceptionCell } from "~/server/mesocycle/schedule-adapters";
import { DAY_FULL } from "~/views/coach";

/**
 * Every date the athlete can still act on: today (their local day) to the block's last
 * day, with how each half is blocked. A standing block wins over an exception, as it does
 * on the board.
 */
export function coachDates(args: {
  startDate: Date;
  lengthWeeks: number;
  timezone: string;
  now: Date;
  standing: AvailabilityCellInput[];
  exceptions: ExceptionCell[];
}): CoachDate[] {
  const start = localDayNumber(args.startDate, args.timezone);
  const today = localDayNumber(args.now, args.timezone);
  const end = start + args.lengthWeeks * 7; // exclusive
  const oneOff = new Set(args.exceptions.map((e) => `${e.date}:${e.daypart}`));
  const out: CoachDate[] = [];
  for (let n = Math.max(today, start); n < end; n++) {
    const date = isoDateOfDayNumber(n);
    const weekday = weekdayOfDayNumber(n);
    const half = (daypart: "AM" | "PM"): BlockSource =>
      args.standing.some((c) => c.day === weekday && c.daypart === daypart && c.state === "BLOCKED" && c.oneOff !== true)
        ? "standing"
        : oneOff.has(`${date}:${daypart}`)
          ? "one_off"
          : null;
    out.push({ date, weekday, weekIndex: Math.floor((n - start) / 7) + 1, am: half("AM"), pm: half("PM") });
  }
  return out;
}

/** What the language model is shown. No ids, no warnings, no readiness: only what it needs
 * to turn a sentence into dates and a session key. */
export interface ModelContext {
  today: string;
  todayWeekday: string;
  scheduleMode: string;
  viewedWeek: number;
  dates: { date: string; weekday: string; week: number; blocked: "no" | "morning" | "afternoon" | "all day" }[];
  sessions: {
    key: string;
    label: string;
    day: string | null;
    time: "morning" | "afternoon" | null;
    status: "scheduled" | "done" | "missed";
  }[];
}

const STATUS = { SCHEDULED: "scheduled", COMPLETED: "done", MISSED: "missed" } as const;

export function toModelContext(week: CoachWeek): ModelContext {
  const first = week.dates[0];
  return {
    today: first?.date ?? "",
    todayWeekday: first ? (DAY_FULL[first.weekday] ?? "") : "",
    scheduleMode: week.mode === "HALF_DAY" ? "morning or afternoon sessions" : "one session a day",
    viewedWeek: week.weekIndex,
    dates: week.dates.map((d) => ({
      date: d.date,
      weekday: DAY_FULL[d.weekday] ?? "",
      week: d.weekIndex,
      blocked: d.am !== null && d.pm !== null ? "all day" : d.am !== null ? "morning" : d.pm !== null ? "afternoon" : "no",

      label: s.label,
```

```ts
import "server-only";
import Anthropic from "@anthropic-ai/sdk";
import { env } from "~/env";
import { CoachIntentFormSchema, type CoachIntentForm } from "~/schema";
import type { ModelContext } from "./context";
import { COACH_SYSTEM_PROMPT, COACH_TOOL_NAME, COACH_TOOL_SCHEMA, userTurn } from "./prompt";

export type CoachFailure = "no_key" | "timeout" | "api_error" | "invalid_form";

export type InterpretResult =
  | { ok: true; form: CoachIntentForm; model: string; inputTokens: number | null; outputTokens: number | null }
  | { ok: false; reason: CoachFailure };

export interface CoachInterpreter {
  interpret(text: string, context: ModelContext): Promise<InterpretResult>;
}

const TIMEOUT_MS = 8000;
const MAX_TOKENS = 400;

export function coachEnabled(): boolean {
  return Boolean(env.ANTHROPIC_API_KEY);
}

/**
 * The intent form out of a model response, or null. Only the forced tool's input is read:
 * any text the model wrote is ignored, and the input is parsed by the same schema the
 * rest of the app trusts.
 */
export function parseToolResponse(content: unknown): CoachIntentForm | null {
  if (!Array.isArray(content)) return null;
  for (const block of content as { type?: unknown; name?: unknown; input?: unknown }[]) {
    if (block?.type !== "tool_use" || block.name !== COACH_TOOL_NAME) continue;
    const parsed = CoachIntentFormSchema.safeParse(block.input);
    return parsed.success ? parsed.data : null;
  }
  return null;
}

export const anthropicInterpreter: CoachInterpreter = {
  async interpret(text, context) {
    if (!env.ANTHROPIC_API_KEY) return { ok: false, reason: "no_key" };
    const client = new Anthropic({ apiKey: env.ANTHROPIC_API_KEY, timeout: TIMEOUT_MS, maxRetries: 0 });
    try {
      const res = await client.messages.create({
        model: env.COACH_MODEL,
        max_tokens: MAX_TOKENS,
        system: COACH_SYSTEM_PROMPT,
        tools: [
          {
            name: COACH_TOOL_NAME,
            description: "Record what the athlete's message means.",
            input_schema: COACH_TOOL_SCHEMA as Anthropic.Tool.InputSchema,
          },
        ],
        tool_choice: { type: "tool", name: COACH_TOOL_NAME },
        messages: [{ role: "user", content: userTurn(text, context) }],
      });
      const form = parseToolResponse(res.content);
      if (form === null) return { ok: false, reason: "invalid_form" };
      return {
        ok: true,
        form,
        model: res.model,
        inputTokens: res.usage?.input_tokens ?? null,
        outputTokens: res.usage?.output_tokens ?? null,
      };
    } catch (err) {
      return { ok: false, reason: err instanceof Anthropic.APIConnectionTimeoutError ? "timeout" : "api_error" };
    }
  },
};
```

```ts
 * cell leaves no trace. The current week is only recorded (the board then offers
 * options); each later week touched is re-arranged once, whatever number of its days
 * were blocked. Must run inside a transaction that already holds the block lock.
 */
async function applyExceptions(tx: Tx, userId: string, cells: ExceptionInput[], now: Date): Promise<WeekResult[]> {
  // Week 1 always exists; it gives us the block's dates and the athlete's settings.
  const block = await loadWeekContext(tx, userId, 1, now);
  const tz = block.settings.timezone;
  const start = localDayNumber(block.startDate, tz);
  const today = localDayNumber(now, tz);

  const weekOf = new Map<ExceptionInput, number>();
  for (const cell of cells) {
    const day = dayNumberOfIsoDate(cell.date);
    if (day < start || day >= start + block.lengthWeeks * 7) {
      throw new TRPCError({ code: "BAD_REQUEST", message: "That date is outside your current block." });
    }
    if (day < today) throw new TRPCError({ code: "BAD_REQUEST", message: "That day has already passed." });
    if (block.settings.mode === "DAY" && cell.daypart !== null) {

        date: dbDate(cell.date),
```

```ts
import type { CoachSession, CoachWeek } from "~/domain/coach/resolve";
import { explainPlacement, isStranded, placementPosition, savedLayout, scoreLayout, suggestMoves } from "~/engine";
import type { WeekContext } from "~/server/schedule/week-context";
import type { NextSessionInfo, ReadinessInfo } from "~/views/coach";
import { toMoveSuggestionView, toWarnings } from "~/views/schedule";
import { coachDates } from "./context";

/** The athlete's week as the coach resolver needs it. Session keys S1…Sn follow board order. */
export function coachWeekFrom(c: WeekContext, extras: { now: Date; readiness: ReadinessInfo | null }): CoachWeek {
  const layout = savedLayout(c.input);
  const ordered = [...c.week.sessions].sort((a, b) => a.order - b.order);
  const sessions: CoachSession[] = ordered.map((s, i) => ({
    key: `S${i + 1}`,
    id: s.id,
    label: s.splitSlot,
    status: s.status,
    placement: layout[s.id] ?? null,
  }));

  const stranded = isStranded(c.input);
  const top = stranded ? undefined : suggestMoves(c.input, layout)[0];
  const suggestion = top ? toMoveSuggestionView(top, c.label) : null;

  // The next session: the first still to train, in the order the week lays them out.
  const upcoming = ordered
    .filter((s) => s.status === "SCHEDULED")
    .sort((a, b) => {
      const pa = layout[a.id];
      const pb = layout[b.id];
      if (!pa || !pb) return (pa ? 0 : 1) - (pb ? 0 : 1) || a.order - b.order;
      return placementPosition(pa, c.input.weekStartDay) - placementPosition(pb, c.input.weekStartDay) || a.order - b.order;
    })[0];
  const firstPx = upcoming ? [...upcoming.prescriptions].sort((a, b) => a.order - b.order)[0] : undefined;
  const next: NextSessionInfo | null = upcoming
    ? {
        label: upcoming.splitSlot,
        placement: layout[upcoming.id] ?? null,
        minutes: upcoming.targetDurationMin ?? 0,
        first: firstPx
          ? {
              exerciseName: firstPx.exercise.name,
              sets: firstPx.sets,
              repLow: firstPx.targetRepLow ?? 0,
              repHigh: firstPx.targetRepHigh ?? 0,
            }
          : null,
      }
    : null;

  return {
    mode: c.settings.mode,
    weekIndex: c.week.index,
    dates: coachDates({
      startDate: c.startDate,
      lengthWeeks: c.lengthWeeks,
      timezone: c.settings.timezone,
      now: extras.now,
      standing: c.settings.availability,
      exceptions: c.exceptions,
    }),
    sessions,
    stranded,
    warnings: toWarnings(scoreLayout(c.input, layout).facts, c.label),
    suggestion: suggestion ? { headline: suggestion.headline, reasons: suggestion.reasons } : null,
    next,
    readiness: extras.readiness,
    explain: (sessionId) => explainPlacement(c.input, layout, sessionId),
  };
}
```

```ts
import { TRPCError } from "@trpc/server";
import type { Prisma } from "../../../../generated/prisma";
import { readinessState } from "~/components/viz/readiness-state";
import { resolveCoachForm } from "~/domain/coach/resolve";
import { COACH_DAILY_LIMIT, CoachMessageInputSchema } from "~/schema";
import { createTRPCRouter, protectedProcedure } from "~/server/api/trpc";
import { anthropicInterpreter, coachEnabled, type InterpretResult } from "~/server/coach/client";
import { toModelContext } from "~/server/coach/context";
import { coachWeekFrom } from "~/server/coach/week";
import { BLOCK_FOR_READINESS_SELECT, readinessSamplesFrom } from "~/server/mesocycle/readiness-samples";
import { loadWeekContext } from "~/server/schedule/week-context";
import { FINISHED_WEEK_LINES, LIMIT_LINES, UNAVAILABLE_LINES, type CoachReply, type ReadinessInfo } from "~/views/coach";

const DAY_MS = 24 * 60 * 60 * 1000;
const asJson = (value: unknown) => JSON.parse(JSON.stringify(value)) as Prisma.InputJsonValue;

export const coachRouter = createTRPCRouter({
  // Whether the coach box should be shown at all.
  status: protectedProcedure.query((): { enabled: boolean } => ({ enabled: coachEnabled() })),

  // Read a message and say what it would do. Changes no schedule state: every change
  // is made later, from a confirm card, by the schedule and session procedures.
  interpret: protectedProcedure.input(CoachMessageInputSchema).mutation(async ({ ctx, input }): Promise<CoachReply> => {
    const userId = ctx.session.user.id;
    const now = new Date();
    const c = await loadWeekContext(ctx.db, userId, input.weekIndex, now);
    if (c.readOnly) return { kind: "unsupported", lines: FINISHED_WEEK_LINES };
    if (!coachEnabled()) return { kind: "unavailable", lines: UNAVAILABLE_LINES };

    const sent = await ctx.db.coachMessage.count({
      where: { athleteProfileId: c.athleteProfileId, createdAt: { gte: new Date(now.getTime() - DAY_MS) } },
    });
    if (sent >= COACH_DAILY_LIMIT) return { kind: "unavailable", lines: LIMIT_LINES };

    // Readiness is one of the four answers. It is best-effort: without it the answer
    // says there is not enough logged training, which is true of an empty block too.
    let readiness: ReadinessInfo | null = null;
    try {
      const block = await ctx.db.mesocycle.findFirst({
        where: { status: "ACTIVE", athleteProfile: { userId } },
        select: BLOCK_FOR_READINESS_SELECT,
      });
      const samples = block ? readinessSamplesFrom(block) : [];
      const point = samples.filter((s) => s.weekIndex <= c.currentWeek).at(-1);
      if (point) readiness = { fitness: point.fitness, fatigue: point.fatigue, form: point.form, label: readinessState(point) };
    } catch {
      readiness = null;
    }

    const week = coachWeekFrom(c, { now, readiness });

    let result: InterpretResult;
    try {
      result = await anthropicInterpreter.interpret(input.text, toModelContext(week));
    } catch {
      result = { ok: false, reason: "api_error" };
    }
    const reply: CoachReply = result.ok ? resolveCoachForm(result.form, week) : { kind: "unavailable", lines: UNAVAILABLE_LINES };

    await ctx.db.coachMessage.create({
      data: {
        athleteProfileId: c.athleteProfileId,
        weekIndex: input.weekIndex,
        text: input.text,
        form: result.ok ? asJson(result.form) : (null as unknown as Prisma.InputJsonValue),
        outcome: result.ok ? reply.kind : result.reason,
        model: result.ok ? result.model : null,
        inputTokens: result.ok ? result.inputTokens : null,
        outputTokens: result.ok ? result.outputTokens : null,
      },
    });
    return reply;
  }),
});
```

```tsx
"use client";

import { useState } from "react";
import { RescheduleDialog } from "~/components/block/reschedule-dialog";
import { COACH_MAX_TEXT } from "~/schema";
import { api } from "~/trpc/react";
import type { CoachFinalReply, CoachReply } from "~/views/coach";
import { CoachReplyCard } from "./coach-reply";

export interface AppliedWeek {
  weekIndex: number;
  moved: string[];
  needsChoice: boolean;
}

/** Type what changed or what you want to know. The server works out what it means and
 * answers from the engine; nothing changes until a card is confirmed. */
export function CoachBox({
  weekIndex,
  blocked,
  onApplied,
}: {
  weekIndex: number;
  /** Why a change cannot be confirmed right now (an open draft), or null. */
  blocked: string | null;
  /** Blocked time changed: the board refetches and reports what moved. */
  onApplied: (weeks: AppliedWeek[]) => Promise<void> | void;
}) {
  const utils = api.useUtils();
  const [text, setText] = useState("");
  const [reply, setReply] = useState<CoachReply | null>(null);
  const [skipping, setSkipping] = useState<string | null>(null);

  const interpret = api.coach.interpret.useMutation({
    onSuccess: (r) => {
      setReply(r);
      setText("");
    },
  });
  const block = api.schedule.setExceptions.useMutation({
    onSuccess: async (res) => {
      setReply(null);
      await onApplied(res.weeks);
    },
  });
  const unblock = api.schedule.clearExceptions.useMutation({
    onSuccess: async () => {
      setReply(null);
      await onApplied([]);
    },
  });
  const pending = interpret.isPending || block.isPending || unblock.isPending;

  function send() {
    const trimmed = text.trim();
    if (trimmed === "" || pending) return;
    block.reset();
    unblock.reset();
    interpret.mutate({ weekIndex, text: trimmed });
  }

  function confirm(r: Extract<CoachFinalReply, { kind: "confirm_block" | "confirm_unblock" }>) {
    if (r.kind === "confirm_block") block.mutate({ cells: r.cells });
    else unblock.mutate({ cells: r.cells });
  }

  const error = block.error?.message ?? unblock.error?.message ?? null;

  return (
    <div className="flex flex-col gap-3">
      <form
        className="flex items-center gap-2"
        onSubmit={(e) => {
          e.preventDefault();
          send();
        }}
      >
        <label htmlFor="coach-box" className="sr-only">
          Tell the coach
        </label>
        <input
          id="coach-box"
          type="text"
          value={text}
          maxLength={COACH_MAX_TEXT}
          onChange={(e) => setText(e.target.value)}
          placeholder="Tell the coach: can’t make Thursday, or ask why a session is where it is"
          disabled={interpret.isPending}
          autoComplete="off"
          className="rounded-control border-border-subtle bg-canvas text-nav text-fg placeholder:text-fg-subtle min-w-0 flex-1 border px-3 py-2"
        />
        <button
          type="submit"
          disabled={pending || text.trim() === ""}
          className="rounded-control border-border text-nav text-fg-soft hover:text-fg border px-3 py-2 font-medium transition-colors disabled:opacity-60"
        >
          {interpret.isPending ? "Thinking…" : "Send"}
        </button>
      </form>
      {interpret.isError ? (
        <p className="text-nav text-fg-soft" role="status">
          {interpret.error.data?.code === "NOT_FOUND" ? "That week isn’t available." : "Something went wrong sending that. Try again."}
        </p>
      ) : null}
      {reply ? (
        <CoachReplyCard
          reply={reply}
          pending={pending}
          blocked={blocked}
          error={error}
          onConfirm={confirm}
          onSkip={setSkipping}
          onChoose={setReply}
          onDismiss={() => setReply(null)}
        />
      ) : null}
      {skipping !== null ? (
        <RescheduleDialog
          sessionId={skipping}
          open
          title="Skip this session?"
          onClose={() => {
            setSkipping(null);
            setReply(null);
            void utils.schedule.invalidate();
          }}
        />
      ) : null}
    </div>
  );
}
```
